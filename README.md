# FPS-Local-Co-op
Join up to 4 friends to jump into increasingly difficult procedural dungeons. Fight baddies, get loot, extract, buy weapons, repeat. 
Runs on old original XBox One hardware.

No great way to test this, can build solution for .net and then I used Visual Studio to build into a deployable. Then need an Xbox in dev mode that you can connect to its wifi, open its portal in a Windows OS browser, and do a file upload of the game. Only then can you configure and play the thing on Xbox. 

Not worth the trouble to check out my proj running natively on Xbox unless you really want it. I would recommend just connecting some controllers to your computer and running it in the editor. Note that it only works with Xbox controllers.
